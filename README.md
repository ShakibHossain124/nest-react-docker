# AppFlow

**AppFlow** is a full-stack task and workflow management application built to demonstrate modern frontend and backend development with a containerized architecture.

The application provides a clean interface for managing tasks and organizing workflow-related activities, backed by a structured REST API.

## 🚀 Live Demo

**[AppFlow](https://appflow-fhdi.onrender.com)**

## 🛠️ Tech Stack

* **Frontend:** React, TypeScript
* **Backend:** NestJS, TypeScript
* **Database:** PostgreSQL
* **ORM:** Prisma
* **Containerization:** Docker & Docker Compose
* **API:** REST
* **Deployment:** Render

## ✨ Features

* User-friendly task/workflow management interface
* Create, view, update, and delete tasks
* RESTful backend API
* Structured NestJS backend architecture
* PostgreSQL database integration with Prisma
* Responsive frontend interface
* Dockerized development environment
* Frontend and backend separated into independent applications

## 📌 Project Overview

AppFlow was built as a practical full-stack project to explore how a **React frontend and NestJS backend** can work together in a production-oriented architecture.

The project focuses on clean separation of concerns, API-driven communication, database persistence, and containerized development using Docker Compose.
